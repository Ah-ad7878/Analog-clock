# 🕒 Dark Neumorphic Analog Clock

A sleek, dark-themed **Neumorphic Analog Clock UI** built in Flutter. This project showcases realistic 3D depth, soft drop shadows, and high-performance custom drawing techniques to deliver a minimalist clock interface.

---

## 🎨 Color Palette & Design Tokens

| UI Element | HEX Code | Purpose |
| :--- | :--- | :--- |
| **App Background** | `#2B2B2B` | Soft dark background tone |
| **Outer Clock Frame** | `#2B2B2B` | Raised neumorphic base plate |
| **Inner Dial Face** | `#222222` | Recessed clock dial |
| **Accent Markers (12, 3, 6, 9)** | `#00E676` | Vibrant green hour ticks |
| **Hour & Minute Hands** | `#5B9BFF` | Blue primary indicator hands |
| **Second Hand** | `#FF8C32` | Orange lively second hand |
| **Standard Ticks** | `#FFFFFF` | Muted white minor ticks |

---

## ✨ Architectural Highlights

* **Layered Neumorphic Depth:** Dual-container arrangement using light and dark directional shadows to produce a realistic elevated 3D effect.
* **Precise Canvas Rendering:** Clock tick marks, pin joints, and hands rendered via custom vector graphics operations for crisp display across all pixel densities.
* **Centered Alignment Engine:** Built with strict center-stacking alignment to prevent layout shifts across varying screen viewports.
